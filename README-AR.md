# ORANGE WIFI — موقع تعريفي

موقع عربي باتجاه RTL، متجاوب مع الهاتف والحاسوب، ومجهز للنشر على GitHub Pages.

## محتويات الملف
- `index.html` — بنية الصفحات والأقسام.
- `style.css` — التصميم والألوان والتجاوب.
- `script.js` — القائمة التفاعلية وزر واتساب والسنة التلقائية.

## قبل النشر
1. افتح `script.js`.
2. غيّر قيمة `WHATSAPP_NUMBER` إلى رقمك بصيغة دولية، بدون `+` أو مسافات. مثال توضيحي للمغرب: `2126XXXXXXXX`.
3. افتح `index.html` وعدّل أسماء الباقات ومحتواها وأسعارها بما يطابق عروضك الحقيقية. الأسعار غير محددة في هذا النموذج.
4. عدّل بيانات التواصل والنصوص حسب نشاطك.

## النشر على GitHub Pages
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub الخاص بالموقع.
3. من Settings ثم Pages اختر فرع النشر ومجلد الجذر `/root` (أو `/` حسب واجهة GitHub).
4. احفظ وانتظر اكتمال النشر.

## ملاحظات
- لا يحتوي القالب على نظام تسجيل دخول أو دفع إلكتروني أو إدارة اشتراكات.
- الخط يُحمّل من Google Fonts، لذلك قد يظهر خط بديل عند عدم توفر الإنترنت.
- الباقات والأسعار في القالب أمثلة تصميمية وليست عروضاً فعلية.
